Hardware Security · Side-Channel Tooling

ChipWhisperer Studio

Released on PyPI106-tool MCP server

A cross-platform desktop app for NewAE's ChipWhisperer side-channel and fault-injection hardware, so the full workflow runs without writing Python or opening Jupyter. Live waveforms, N-trace capture, progressive CPA with five AES leakage models, glitch parameter sweeps with a live scatter plot, UART/SPI/JTAG/SWD interfaces, a logic analyser with eight protocol decoders, and firmware emulation that maps functions and source lines onto the power trace.
